# Community team

This project is currently presented as an open community preview. Do not imply
that upstream maintainers endorse or maintain the Windows additions.

## Current status

No formal community maintainer roster is recorded yet. Contributors are
credited through Git history and release notes, and names are added here only
with their consent.

## Roles being sought

- Desktop maintainer: Electron, Windows BLE and DPAPI.
- Android interoperability maintainer: official-source tracking and physical testing.
- Protocol reviewer: Apple/Android contract and Noise/Nostr interoperability.
- Security reviewer: threat modeling, IPC, key storage and supply chain.
- Release manager: signed artifacts, provenance and release gates.
- UX/accessibility contributors: Desktop behavior, localization and assistive technology.

## Working rules

- Decisions with security or protocol impact require a written issue and review.
- No platform is described as supported until its release gate passes.
- Upstream changes remain attributable and are never silently rewritten.
- Maintainers disclose conflicts and do not publish another contributor's identity without consent.
- Confirmed vulnerabilities are handled privately under `SECURITY.md`.
